## Шаг 2 — сертификат (СДЕЛАНО)
```
ssh training-vps
certbot --nginx -d robertfitchell.ru -d www.robertfitchell.ru --redirect
```
Certbot сам допишет HTTPS-блок и редирект http→https. После этого включаем
редирект www → без www.

## Откат
Если что-то пойдёт не так — вернуть в REG.RU четыре A-записи GitHub и CNAME для
www. Репозиторий и Pages остаются нетронутыми до шага 3, так что откат — это
одна правка DNS.

## Честно про риск
training-vps — один сервер (Timeweb, 1 ГБ RAM), на нём же живут «Живой тренинг»
и gdePit. Сайт-визитка почти ничего не ест, но если сервер ляжет — ляжет и сайт,
чего с GitHub Pages практически не бывало. Для визитки это приемлемо; если сайт
станет основным каналом заявок, стоит взять под него отдельный хостинг.
