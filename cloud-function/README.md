# Приём заявок через Yandex Cloud Function (152-ФЗ)

Форма на сайте отправляет заявки на эту функцию в регионе `ru-central1`.
Данные обрабатываются и пересылаются на почту через серверы в РФ — это
закрывает требование локализации персональных данных (152-ФЗ, ст. 18 ч. 5).

## Шаги деплоя (через консоль Yandex Cloud)

1. **Почта-отправитель.** Заведи (или возьми существующий) ящик на `@yandex.ru`.
   В Яндекс ID → «Безопасность» → «Пароли приложений» создай **пароль приложения**
   для SMTP. Основной пароль от почты использовать нельзя.

2. **Создай функцию.** Консоль Yandex Cloud → Cloud Functions → «Создать функцию».
   - Среда выполнения: **Python 3.12**.
   - Загрузи файлы `handler.py` и `requirements.txt` из этой папки.
   - Точка входа: `handler.handler`.
   - Таймаут: 10 сек, память: 128 МБ.

3. **Переменные окружения** функции (вкладка «Параметры»):
   | Переменная | Значение |
   |---|---|
   | `SMTP_USER` | `robot@yandex.ru` (твой ящик-отправитель) |
   | `SMTP_PASS` | пароль приложения из шага 1 |
   | `MAIL_TO` | куда слать заявки, напр. `fitchellr@yandex.ru` |
   | `ALLOW_ORIGIN` | `https://robertfitchell.ru` |

4. **Сделай функцию публичной.** В настройках функции включи
   «Публичная функция» — тогда форма сможет к ней обращаться без авторизации.

5. **Скопируй URL** вызова функции (вида
   `https://<id>.functions.yandexcloud.net/`) и вставь его в `index.html`
   вместо `https://CHANGE-ME.functions.yandexcloud.net/`
   (атрибут `action` у `<form id="contact-form">`).

6. Закоммить и запушь сайт — заявки пойдут на почту.

## Проверка

```bash
curl -X POST https://<id>.functions.yandexcloud.net/ \
  -H "Content-Type: application/json" \
  -d '{"name":"Тест","phone":"+70000000000","program":"Аудит","consent":true}'
# Ожидаемый ответ: {"ok": true}
```

## Что ещё нужно по 152-ФЗ (вне кода)

- Подать **уведомление оператора ПДн** в Роскомнадзор (на сайте РКН).
- Проверить, что `privacy.html` описывает: какие данные собираются,
  цель (обратная связь по заявке), срок хранения, что обработка ведётся
  в РФ. Ссылка на неё уже добавлена в чекбокс согласия под формой.
